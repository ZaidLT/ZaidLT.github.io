  • AI home operations: co-led a Google ADK platform with 16 specialist agents and typed tools for product actions. Served as the primary memory-service engineer and owned voice and messaging. Shipped seven capabilities across document intelligence, persistent memory and service workflows.

  • Evaluation and delivery: built the 303-fact, 729-query memory evaluation harness; the chosen OpenAI + Markdown configuration achieved Recall@3 of 93.8% and MRR@3 0.878. Deployed two MCP servers on Google Cloud Run, exposing existing ADK platform tools to other agent clients.
  • Cloud operations: as the only cloud engineer, owned architecture, deploys and on-call for the collection platform, covering identity, private networking, secrets, migrations, incident recovery, cost monitoring and runbooks.
